From BricsCAD to a clean DXF

Draft · updated November 26, 2026 · to be reviewed by Michaël

A “clean” DXF for SheetCam (or another 2D CAM) is a file whose units, version, and geometry match what the CAM can read: closed contours, no proxy objects, and precision the machine can use.

The official command: DXFOUT

According to the BricsCAD (Lite and Pro) help, DXFOUT saves the current drawing to DXF. Documented options:

  • Decimal places (0 to 16). The help notes that some CNC machines require 4 decimal places in DXF files.
  • Entities. Export only the selected entities. If you leave this unspecified, everything is exported.
  • Binary. Binary format. If unspecified, the file is ASCII (text), usually preferable for CAM.
  • Version. DXF version number. The default is the most current. Exporting to an older version can drop entities or properties.

The EXPORT command also exists for other formats. For a typical plasma workflow, DXFOUT is the official starting point.

Proxy objects and cleanup

If the drawing holds AEC or custom proxy objects the CAM will not recognize, BricsCAD documents EXPORTTOAUTOCAD to convert them into native blocks. WBLOCK can also extract usable geometry.

A usual cleanup before export (PURGE unused definitions, including nested ones; merge or delete leftover layers) reduces import surprises. Confirm that drawing units match what SheetCam expects (see the two unit settings in the SheetCam guide).

Pre-CAM checklist

Shop practice to confirm on your own workflow — not a software guarantee:

  • Drawing units confirmed (mm or inches) and noted for the SheetCam import.
  • 2D cutting geometry, closed contours (joined polylines or arcs).
  • Separate layers for cut, mark, bend, or etch, following your shop convention.
  • Title blocks, dimensions, hatches, and presentation text left out of the export (Entities option) if they clutter the CAM.
  • No leftover proxy objects; DXF version and decimal places chosen (4 places if your machine requires it).
  • ASCII rather than binary, unless you have a specific reason.
