Getting started with SheetCam (French companion)

Draft · updated November 26, 2026 · to be reviewed by Michaël

SheetCam is CAM software for 2D cutting — plasma, oxy-fuel, waterjet, laser. It is not a CAD program. The official manuals are in English. This page is a French-first companion, not a substitute for those manuals.

Official starting points

From SheetCam LLC Support Manuals: the 8.0 Quick Start Guide, Auto Nesting Quick Start, 2D CAD Quick Start, and the manual (A4 and US Letter, including a plasma / metric edition). In the software: Help → Tutorials.

According to a SheetCam staff reply on the official forum, the trial is the same executable as the licensed build, with no time limit, but it only produces about 180 lines of G-code.

Two unit settings, often mixed up

The same staff note: linear units are set in two independent places.

  • Options → Application options — the design canvas.
  • Options → Machine → Post Processor — the units written into the G-code.

They do not have to match, but a misunderstood mismatch makes parts come out at the wrong scale. Also: the built-in tutorials change Job options (material, work area, table size). Plan to set them back for your machine.

Typical workflow (no invented parameters)

This sequence follows SheetCam’s documented flow and public quick-start write-ups. Lead lengths, kerf, and speeds must come from your plasma source, post-processor, and tests — not from this page.

  1. New job. File → New job, then Options → Job options: work area, thickness if you track it here, origin (often lower left, X0,Y0), rapid clearance.
  2. Import the drawing. File → Import drawing… (DXF, SVG, and so on). Match scale and units. A microscopic or gigantic part is almost always a unit mismatch.
  3. Check geometry. Open contours, duplicates, or unexploded blocks are best fixed in CAD (see the BricsCAD guide).
  4. Minimum to get a toolpath. Per SheetCam staff: at least one Part (a DXF import already lands in a Part), one Layer, one Tool (preferably two), and one Operation (for plasma: Jet / Plasma Cut).
  5. Plasma operation. Operations → New operation → Plasma Cut. Typical contour methods: outside for the profile, inside for holes, no offset for marking. Leads and cut direction depend on your torch and chart — do not copy a random “standard” lead length.
  6. Post-processor. Options → Machine → Post Processor, pick the one for your control. Then File → Post process to write the NC file.

Automatic nesting in version 8

Per SheetCam’s v8 FAQ and quick start, AutoNesting uses existing toolpaths (kerf offset, lead-in and lead-out), not just raw geometry. Open the module with no operation and it does nothing. The software offers several variants; you pick one and Apply. Manual nesting is still there.

What this page will not do

It will not publish a speed or kerf table “for X mm mild steel.” Those numbers belong to your manufacturer’s chart and to tests on your table. See Kerf and cut quality.
