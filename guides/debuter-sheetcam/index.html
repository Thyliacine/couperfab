Débuter avec SheetCam en français

Brouillon · mis à jour le 26 novembre 2026 · à réviser par Michaël

SheetCam est un logiciel de FAO (CAM) pour la découpe 2D — plasma, oxycoupage, jet d’eau, laser. Ce n’est pas un logiciel de DAO. Les manuels officiels sont en anglais ; cette page est un compagnon francophone, pas un substitut.

Où trouver l’officiel

Chez SheetCam LLC (page Support Manuals) : guide de démarrage rapide 8.0, guide d’imbricage automatique, guide 2D CAD, et le manuel (formats A4 et US Letter, y compris une version « plasma, unités métriques »). Dans le logiciel : menu Help → Tutorials pour des démarches pas à pas.

La version d’essai, d’après une réponse de l’équipe SheetCam sur le forum officiel, est le même exécutable que la version licenciée, sans limite de temps, mais elle ne produit qu’environ 180 lignes de G-code. Téléchargement : le site de SheetCam LLC.

Deux réglages d’unités, souvent confondus

Même source (équipe SheetCam, forum) : il y a deux endroits pour les unités linéaires, et ils sont indépendants.

  • Options → Application options : unités du canevas de conception.
  • Options → Machine → Post Processor : unités du G-code envoyé à la machine.

Ils n’ont pas à être identiques, mais un décalage mal compris donne des pièces trop petites ou trop grandes. Vérifiez les deux avant le premier essai.

Les tutoriels intégrés, toujours selon cette même note officielle, modifient les Options / Job options (matière, zone de travail, taille de table). Prévoyez de les remettre à votre machine après le tutoriel.

Démarche typique (sans paramètres inventés)

La séquence ci-dessous reprend le flux documenté par SheetCam et des guides d’utilisation publics (notamment le démarrage rapide publié par des intégrateurs). Les valeurs de jeu, de longueur d’entrée et de vitesse doivent venir de votre source plasma, de votre post-processeur et de vos essais — pas de cette page.

  1. Nouveau job. File → New job. Puis Options → Job options : zone de travail, épaisseur si vous la suivez ici, origine (souvent le coin inférieur gauche, X0,Y0), hauteur de dégagement des rapides. Validez.
  2. Importer le dessin. File → Import drawing… (DXF, SVG, etc.). Dans le dialogue, alignez l’échelle et les unités sur le fichier. Si la pièce est minuscule ou énorme, c’est presque toujours un conflit d’unités : réimportez.
  3. Vérifier la géométrie. Contours ouverts, traits en double, ou blocs non explosés se règlent idéalement dans le DAO (voir le guide BricsCAD). SheetCam offre aussi des outils de réparation : utilisez-les en sachant ce que vous changez.
  4. Minimum requis pour un parcours. D’après l’équipe SheetCam : au moins une pièce (Part — un import DXF arrive déjà dans une pièce), une couche (Layer), un outil (idéalement deux, pour les règles et comparaisons), et une opération (pour le plasma : Jet / Plasma Cut).
  5. Opération plasma. Operations → New operation → Plasma Cut. Méthode de contour typique : extérieur pour le profil, intérieur pour les trous, sans décalage pour un traçage. Choisissez la couche et l’outil. Les entrées/sorties (lead-in / lead-out) et le sens de coupe dépendent de votre chalumeau et de votre charte — ne copiez pas une longueur « standard » trouvée au hasard.
  6. Post-processeur. Options → Machine → Post Processor : choisissez celui qui correspond à votre commande. S’il n’est pas dans la bibliothèque, SheetCam documente une API et peut citer un travail sur mesure (sales@sheetcam.com, d’après le forum officiel). Puis File → Post process pour écrire le fichier NC.

Imbricage automatique (version 8)

Selon la FAQ et le guide rapide v8 de SheetCam, l’imbricage automatique s’appuie sur les parcours déjà créés (décalage de kerf, entrées et sorties), pas seulement sur le contour. Si vous ouvrez le module sans opération, il ne fait rien. Le logiciel calcule plusieurs variantes ; vous en choisissez une, puis Apply. L’imbricage manuel reste disponible.

Ce que cette page ne fait pas

Elle ne donne pas de tableau de vitesses, de kerf ou d’avance « pour l’acier doux X mm ». Ces chiffres doivent venir de la charte du fabricant de votre source, puis d’essais sur votre table. Voir le guide Kerf et qualité de coupe.

À valider en atelier (Michaël)

  • Quels post-processeurs sont réellement utilisés dans les ateliers québécois que vous connaissez (Machitech, FastCAM, contrôleurs courants, etc.) ?
  • Un modèle de job typique (taille de table, origine, unités) à proposer en exemple, sans le présenter comme universel.
  • Toute imprécision sur les menus de la v8 par rapport à votre copie de travail.
